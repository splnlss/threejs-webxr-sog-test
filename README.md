# Three.js WebXR SOG Test

An experimental Three.js and WebXR viewer for streamed SOG Gaussian splat scenes,
designed for desktop browsers and Meta Quest 2. Rendering uses
[Gaussian Splat Lite](https://github.com/WilliamLiu-1997/Gaussian-Splat-Lite).

The prototype loads the Ronda Lobato scene automatically, streams levels of detail
as you explore, and provides an **Enter VR** button in the upper-left corner.
Controls include desktop orbit navigation and Quest thumbstick movement with
snap turning.
